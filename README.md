# FORDAYS カレンダー連携アプリ

Googleカレンダー「FORDAYS」の予定を読み込み、月間カレンダー表示・リスト表示・スマホでの詳細確認およびカレンダー登録ができるWebアプリケーションです。

## 主な機能

- 📅 **月間カレンダー表示**: スマホに最適化された月間グリッド表示。日付タップでその日の予定が一覧表示されます。
- 📋 **リスト表示**: 日付順に並んだ予定一覧。キーワード検索や「今後の予定のみ」フィルター機能付き。
- 📱 **スマホ最適化＆カレンダーワンタップ登録**:
  - **iPhone / スマホ標準カレンダーに追加**: `.ics` ファイルを生成・ダウンロードし、iOSのカレンダー追加シートや標準カレンダーアプリを直接起動して保存可能。
  - **Googleカレンダーに追加**: Googleカレンダーの予定追加画面を直接開くリンクを提供。
  - **場所のGoogleマップ連携**: 開催場所をタップするとGoogleマップで直接開けます。
- 🔄 **Googleカレンダー最新同期**: サーバー側で定期的に最新の予定を取得。初期状態や未設定時もサンプルデータで動作確認可能。

## Googleカレンダー連携設定（Vercel）

### 1. GoogleカレンダーでiCal URLを取得
1. パソコンのブラウザで [Googleカレンダー](https://calendar.google.com) を開きます。
2. 左メニューの「マイカレンダー」から「FORDAYS」の右側にある縦3点リーダーをクリックし、**「設定と共有」**を選択します。
3. 下部の「カレンダーの統合」セクションにある **「iCal 形式の非公開 URL」**（または「iCal 形式の公開 URL」）をコピーします。

### 2. Vercelの環境変数に登録
1. Vercelのダッシュボードで対象プロジェクトを開きます。
2. **Settings** > **Environment Variables** に移動します。
3. 以下を追加して **Save** します：
   - **Key**: `GOOGLE_CALENDAR_ICAL_URL`
   - **Value**: コピーしたiCal URL
4. 最新コミットを再デプロイ（Redeploy）すると、実際のFORDAYSカレンダーの予定が自動で反映されます。

## ローカル開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デプロイ

GitHubの `main` ブランチにプッシュすると、連携されたVercelにより自動的にビルド＆デプロイされます。
